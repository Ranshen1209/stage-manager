# 版本记录

## 0.3.4 · 2026-09-15

- 删除加入白名单、恢复成功和显示器切换等普通操作通知。
- 侧栏底部不再显示黄色通知卡片，也不保留占位空白；需要处理的异常可在总览查看。

验证：Release 构建和 XAML 静态检查通过。本次为提示显示调整，未新增测试或运行窗口测试。

## 0.3.3 · 2026-09-15

- 新增应用白名单，支持从已打开的窗口多选、选择 EXE 文件，以及右键窗口卡片或组内成员添加；提供开关与移除入口，设置持久保存。
- 白名单应用不参与托管分组，临时打开文件管理器或消息工具时保留当前组；切组、平铺和退出不调整白名单窗口。初始列表为空，由用户选择应用。
- 从窗口添加优先识别具体应用身份；选择 EXE 按完整路径匹配，避免误放行同名程序。应用新增窗口沿用规则。
- 侧栏拉宽后自动切为 2 列、3 列或更多列；预览随卡片宽度调整，卡片顶部对齐，列数计算预留固定滚动条空间。
- 禁止侧栏最大化，保留边框缩放；通过“展开总览”进入可最大化的大视图。修复旧版可能留下的铺满工作区的侧栏尺寸。
- 设置、分组与恢复记录的原子替换遇到短暂文件占用时有限重试；持续失败仍保留原文件并报告错误。

验证：147 项逻辑测试通过，新增 XAML 控件名称已静态核对。本次未运行窗口、截图或真实桌面交互测试。

## 0.3.2 · 2026-09-14

- 新增“设置 → 鼠标手势”：按住中键左右移动，切换 Windows 虚拟桌面。默认关闭，升级不会自动开启。
- 支持反转方向，触发距离可在 40–240 个逻辑像素间调整，并随鼠标所在屏幕的 DPI 换算。
- 每次按住最多切换一次；小范围抖动按普通点击处理，拖动或取消后不补发点击。开启时普通中键点击在松开后执行，并占用原生中键拖动。
- 全屏、组合按键和权限受限的窗口跳过手势。合成输入使用系统桌面快捷键，对不完整发送进行按键释放处理。
- 驻留托盘或暂停调度时仍可使用；关闭开关或退出时释放监听。隔离演示不监听中键或切换实际桌面。
- 保留 0.3.1 的窄侧栏和远程物理 / 虚拟屏分组保护。

验证：124 项逻辑测试通过，包括 21 项新增手势测试。本次未运行窗口测试、实际桌面切换或真实远程手势测试。

## 0.3.1 · 2026-09-14

- 侧栏最小宽度由 244 降至 180 个逻辑像素，窗口卡片同步收窄，保留滚动条空间，避免宽度来回变化。
- 修复小于 200 像素的侧栏宽度无法保存的问题；切换总览、重新启动和 DPI 换算后保留窄侧栏尺寸。
- 远程软件切换物理屏与虚拟屏时，等待中间状态稳定，再整体迁移同屏分组，保留组名、成员顺序和最近使用的成员。
- 屏幕切换期间临时隐藏的窗口有短暂等待期；虚拟屏先开、物理屏后关时保留暂时离开管理范围的分组。
- 屏幕稳定后使用 Windows 已调整的位置。重启本应用时，支持把已移除显示器上的分组关联到仍然存在的窗口，避免恢复旧屏幕坐标。
- 仍然保持每块屏幕独立管理；真正关闭、隐藏到托盘或跨 Windows 桌面移动的窗口不会被重开或拉回。

验证：103 项逻辑测试通过。本次未运行窗口测试、桌面测试或真实远程连接测试。
