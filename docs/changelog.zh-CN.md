# 版本记录

## 0.3.8 · 2026-09-16

- 普通切组改为仅恢复显示状态，使用当前窗口的最大化标记，不再写回缓存位置，避免与 Windows 的 DPI 缩放和切屏重排同时修改窗口。
- 明确恢复布局时，每次只选择一种原生命令，移除先设置窗口布局、再追加位置命令的重复操作。
- 显示切换的稳定性判断增加实际窗口范围、正常位置、DPI、工作区及主窗口 / 侧栏布局；持续变化时继续等待，并冻结日常布局写入和窗口操作。
- 主窗口 / 侧栏停止在中间屏幕配置下反复恢复保存位置；吸附动画同步暂停，待 WPF 完成 DPI 布局后采用当前范围，仅处理越界。
- 新应用窗口位置记录携带坐标空间；明确恢复布局时根据当前 DPI 和工作区一次换算，处理负坐标、任务栏偏移、最大化 / 最小化和临时尺寸限制。原始记录不参与累计缩放，无需固定分辨率配置。
- 切屏期间暂停或退出仅恢复显示状态；请求开启会延后到稳定后执行，暂停可以取消等待。旧版缺少 DPI 信息的应用窗口记录保留当前实际坐标，避免猜测比例。

验证：189 项逻辑测试、Release 构建和 XAML 静态检查通过。按要求未运行窗口、真实 DPI 切换或远程连接测试。本版修复应用自身的坐标回写与恢复时序，尚不能据此保证消除 Windows、远程驱动或目标应用自身的全部窗口变化。

## 0.3.7 · 2026-09-15

- 修复白名单重命名时选中文字被高亮覆盖：统一输入框的选区颜色、透明度及文字颜色，跟随明暗主题。
- 删除设置页的白名单规则数量、手势及快捷键日常黄色状态文字，保留必要错误和冲突说明；移除导航栏底部的品牌 / 版本文字。
- 快捷键改为点击后直接按键录入，松开后自动检查并保存，支持取消、清除和恢复默认。录入时临时捕获按键，保留原有重复、系统保留及注册冲突检测。
- 合并相邻成员的上下半部和中间间隙命中位置，同一插入位置不再显示两个档位的横线。
- 修复侧栏继承总览隐藏筛选，导致拆组后两个独立窗口一起消失：侧栏始终显示全部窗口，拖动完成后立即刷新，返回总览仍保留原筛选。
- 插入提示线居中显示在条目间隙，与卡片边框和两端保持留白；处理多列首尾、换行、不等高卡片及高 DPI 下的裁切和重叠。

验证：172 项逻辑测试、Release 构建和 XAML 静态检查通过。按要求未运行窗口、截图或真实键鼠交互测试，视觉效果及系统按键捕获仍需实际使用验证。

## 0.3.6 · 2026-09-15

- 修复鼠标移到应用白名单区域后设置页滚轮失效：内层列表无需滚动或到达顶部 / 底部时，将滚轮交给外层设置页；列表仍有内容时正常滚动列表，编辑名称时也适用。
- 白名单规则新增行内“重命名”，支持保存 / 取消、Enter / Esc 和输入校验。显示名称持久保存，应用身份、EXE 路径与匹配范围不变。
- 修复保存设置后白名单对象被更新，导致旧按钮引用失效的问题。连续改名和移除现在按稳定的应用身份操作，重复添加也保留自定义名称。

验证：163 项逻辑测试、Release 构建和 XAML 静态检查通过。按要求未运行窗口或真实滚轮交互测试。

## 0.3.5 · 2026-09-15

- 组内窗口条目支持单击置顶对应窗口，避免被列表中排在前面的其他成员盖住；支持 Enter / 空格激活。
- 增加跟随鼠标的莫奈拖动浮层、轻微抬起动画和排序插入线，兼容减少动画设置。拖动源成员暂时淡化，结束或取消后恢复。
- 总览和侧栏均支持组内成员拖动排序、跨组指定位置插入，以及整个分组拖动排序；分组卡片边缘和间隙用于排序，中间区域保留合并操作。
- 排序在松手时一次提交并持久保存，不恢复、最小化或移动实际应用窗口。保留拖动边缘滚动、移出分组与 Esc 取消。
- 缩放时仅更新卡片尺寸，复用成员对象，按变化通知属性；滚动条预留固定宽度，避免显示 / 隐藏时反复改变列数与控件位置。
- 合并每帧布局与原生预览更新，跳过相同预览参数，拖动时保留已有预览。Windows 11 系统圆角不再随每个尺寸变化重复重设窗口区域。
- 移除常驻拖动操作提示占位，目标说明改为仅在拖动浮层中显示。

验证：Release 构建、159 项逻辑测试和 XAML 静态检查通过。按要求未运行窗口、截图或真实桌面交互测试；实际动画和不同屏幕上的视觉效果尚未实测。

## 0.3.3 · 2026-09-15

- 新增应用白名单，支持从已打开的窗口多选、选择 EXE 文件，以及右键窗口卡片或组内成员添加；提供开关与移除入口，设置持久保存。
- 白名单应用不参与托管分组，临时打开文件管理器或消息工具时保留当前组；切组、平铺和退出不调整白名单窗口。初始列表为空，由用户选择应用。
- 从窗口添加优先识别具体应用身份；选择 EXE 按完整路径匹配，避免误放行同名程序。应用新增窗口沿用规则。
- 侧栏拉宽后自动切为 2 列、3 列或更多列；预览随卡片宽度调整，卡片顶部对齐，列数计算预留固定滚动条空间。
- 禁止侧栏最大化，保留边框缩放；通过“展开总览”进入可最大化的大视图。修复旧版可能留下的铺满工作区的侧栏尺寸。
- 设置、分组与恢复记录的原子替换遇到短暂文件占用时有限重试；持续失败仍保留原文件并报告错误。

验证：147 项逻辑测试通过，新增 XAML 控件名称已静态核对。本次未运行窗口、截图或真实桌面交互测试。

## 0.3.2 · 2026-09-14

- 新增“设置 → 鼠标手势”：按住中键左右移动，切换 Windows 虚拟桌面。默认关闭，升级不会自动开启。
- 支持反转方向，触发距离可在 40–240 个逻辑像素间调整，并随鼠标所在屏幕的 DPI 换算。
- 每次按住最多切换一次；小范围抖动按普通点击处理，拖动或取消后不补发点击。开启时普通中键点击在松开后执行，并占用原生中键拖动。
- 全屏、组合按键和权限受限的窗口跳过手势。合成输入使用系统桌面快捷键，对不完整发送进行按键释放处理。
- 驻留托盘或暂停调度时仍可使用；关闭开关或退出时释放监听。隔离演示不监听中键或切换实际桌面。
- 保留 0.3.1 的窄侧栏和远程物理 / 虚拟屏分组保护。

验证：124 项逻辑测试通过，包括 21 项新增手势测试。本次未运行窗口测试、实际桌面切换或真实远程手势测试。

## 0.3.1 · 2026-09-14

- 侧栏最小宽度由 244 降至 180 个逻辑像素，窗口卡片同步收窄，保留滚动条空间，避免宽度来回变化。
- 修复小于 200 像素的侧栏宽度无法保存的问题；切换总览、重新启动和 DPI 换算后保留窄侧栏尺寸。
- 远程软件切换物理屏与虚拟屏时，等待中间状态稳定，再整体迁移同屏分组，保留组名、成员顺序和最近使用的成员。
- 屏幕切换期间临时隐藏的窗口有短暂等待期；虚拟屏先开、物理屏后关时保留暂时离开管理范围的分组。
- 屏幕稳定后使用 Windows 已调整的位置。重启本应用时，支持把已移除显示器上的分组关联到仍然存在的窗口，避免恢复旧屏幕坐标。
- 仍然保持每块屏幕独立管理；真正关闭、隐藏到托盘或跨 Windows 桌面移动的窗口不会被重开或拉回。

验证：103 项逻辑测试通过。本次未运行窗口测试、桌面测试或真实远程连接测试。
